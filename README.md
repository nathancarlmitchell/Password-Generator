# Password-Generator

## A Windows GUI tool to generate random passwords.

Uses Office 365 style passwords by defualt. <br>
Examples:  Kolu4893, Wape1039, Ruti3289 <br><br>
Options can be set to increase length and complexity, from 8 characters to 16, and fully randomized. <br>
Examples: iF4elpP1QRd4J5uh

### Installing
Run setup.exe from 'publish' folder
